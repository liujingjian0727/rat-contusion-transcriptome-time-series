# Input data

The analysis scripts expect the following principal input matrices and metadata files.

## 2026 primary cohort

- `rattus_counts_2026_primary_77samples.txt`
- `rattus_77sample.TMM.TPM.tsv`
- `rattus_meta_2026_77samples.tsv`

The primary cohort contains 77 samples:
7 uninjured Baseline samples and 70 post-injury samples.

## 2021 historical-reference cohort

- `rattus_2021.counts.tsv`
- `rattus_2021.TMM.TPM.tsv`
- `rattus_meta_2021.tsv`

The historical-reference cohort contains 60 samples.

GEO accession: GSE171243.

## Data availability

Large sequencing files and expression matrices are not stored in this GitHub repository.

The 2026 primary sequencing data and processed matrices will be linked to their permanent data repository after accession assignment.
